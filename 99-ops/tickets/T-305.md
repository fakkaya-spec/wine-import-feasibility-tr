## AÇIKLAMA

### Ne iddia ediliyor / ne soruluyor

Tedarikçi görüşmelerinde Incoterm'in **lojistik sonuçları** şunlardır:

| | EXW / FOB alım | CIF alım |
|---|---|---|
| Navlunu kim seçer | **biz** | tedarikçi |
| Rota / armatör / transit süre kontrolü | **bizde** | tedarikçide |
| Konsolidasyon (birden fazla tedarikçiyi tek konteynerde birleştirme) | **mümkün** | zor |
| Liner / reefer kararı | **bizde** | tedarikçide |
| Yükleme mevsimi kontrolü | kısmen bizde | tedarikçide |
| Sigorta klozu | **biz seçeriz** | satıcı seçer |
| Navlun piyasası düşerse fayda | **bize** | tedarikçiye |

### ⚠ Sigorta uyarısı (en önemli nokta)

**CIF Incoterms 2020'de satıcının asgari sigorta yükümlülüğü ICC (C)'dir**
(`EV-2026-08-09-360`). **ICC (C) kırılmayı kapsamaz.**

Şarap kırılgan yüktür. CIF alımda "sigorta var" demek, kırılma karşısında
**fiilen korumasız** olmak anlamına gelebilir. Şarapta gereken teminat:

```
ICC (A) "all risks"
  + kırılma (breakage)
  + termal şok / wine spoilage teminatı        ← EV-2026-08-09-361 ile bu
                                                  teminatların ayrıca satın
                                                  alinabildiği doğrulandı
Teminat değeri: CIF + %10 (kırılgan yükte %15-30'a çıkarılabilir)
```

Taşıyıcının sorumluluğu ise yalnızca **3 USD/kg** ile sınırlıdır
(`EV-2026-08-09-361`) — 1,26 kg'lık dolu bir şişe için ~3,8 USD. Toplu
kırılmada bu yetmez.

### Sorulan

1. Hedef tedarikçiler hangi Incoterm'i tercih ediyor / kabul ediyor?
2. CIF teklif alınırsa **hangi ICC klozunu** kapsadığı yazılı olarak sorulmalı.
3. EXW/FOB mümkünse, yükleme limanı neresi? (rota ve navlun bandımı belirler)
4. Birden fazla tedarikçiden alım yapılacaksa **konsolidasyon** mümkün mü?
   (5.000–10.000 şişe/yıl senaryosunda tek konteyneri doldurmak için kritik)

### Neden önemli — model nerede kırılır

- **Çift sayım:** CIF alımda navlun+sigorta tedarikçi fiyatındadır; modelde
  ayrıca lojistik gideri yazılırsa maliyet iki kez sayılır.
- **Katman karışması:** CIF fiyatı L2'dir, EXW fiyatı L0'dır. Bu ikisi
  karşılaştırılamaz — `CLAUDE.md` §6.
- **Konsolidasyon:** düşük hacim senaryolarında (5.000 şişe/yıl) LCL yerine
  konsolide FCL mümkünse birim maliyet belirgin düşer.
