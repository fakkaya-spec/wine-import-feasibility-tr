**`null`/`UNKNOWN`**'dır. Ters modelde gözetim bir **ALT SINIR** dayatır:

```
ters model uretir :  MAX_CIF_TRY        <- UST SINIR (ticari)
gozetim dayatir   :  CIF_beyan >= esik  <- ALT SINIR (hukuki)
esik > MAX_CIF_TRY  =>  ARADA COZUM YOKTUR
```

**Tavan bugün bir alt sınırla HİÇ TEST EDİLMEMİŞTİR.** Eşik tavanın üstündeyse
**çözüm kümesi boşalır ve proje fiyat pazarlığıyla kurtarılamaz.**
Bu, `finans-fizibilite`'nin **ikinci en güçlü çürütücüsüdür.**
