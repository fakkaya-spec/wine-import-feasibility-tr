## AÇIKLAMA

### Ne iddia ediliyor / ne soruluyor

#### (a) `TBD` string'i güvenlik kontrolünü sessizce geçer

```python
# 80-model/engine/matrah_sirasi.py:217
if meta.get("model_hedef_tarihi") is None:
    sonuc.eksik_girdiler.append(
        "vergi.yaml/meta.model_hedef_tarihi = null -> ..."
    )
```

TUR 1.5 görev tanımı `model_hedef_tarihi`'nin **`TBD` olarak kalmasını**
istiyordu. Literal `"TBD"` yazılsaydı `is None` **False** dönecek ve model
eksik girdiyi **raporlamayacaktı** — CLAUDE.md §1.15 ve §12'nin ihlali.

**Bu ticket'ı açan ajan engine kodunu DEĞİŞTİRMEMİŞTİR** (CLAUDE.md §7 ajan
izolasyonu — `80-model/engine/` `finans-fizibilite` alanıdır). Bunun yerine
`vergi.yaml`'da güvenli temsil seçilmiştir:

```yaml
model_hedef_tarihi: null            # engine kontrolu CALISMAYA DEVAM EDER
model_hedef_tarihi_durum: TBD       # insan okuyucu icin
model_hedef_tarihi_status: UNKNOWN  # CLAUDE.md §12 formati
```

**İstenen düzeltme:** engine, `model_hedef_tarihi` için `is None` yerine
`in (None, "", "TBD", "UNKNOWN", "null")` kontrolü yapmalıdır. Aynı desen
diğer alanlar için de gözden geçirilmelidir.

#### (b) Engine, TUR 1.5'te eklenen iki bloğu okumuyor

> yani kırılma beklenmiyor — ancak `finans-fizibilite` teyit etmelidir.
